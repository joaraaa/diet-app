# 🍱 Diet Tracker

React를 공부하기 위해 직접 만드는 식단 관리 앱입니다.

## 목표

- React 익히기
- 실제 사용할 수 있는 앱 만들기
- GitHub에 개발 과정 기록하기

---

## 개발환경

- React
- Vite
- JavaScript
- CSS
- Git
- Tailwind CSS
- shadcn/ui (shadcn/ui는 Tailwind 위에서 동작하는 UI 컴포넌트 라이브러리)

## Git 커밋 메시지 규칙

- feat: → 새로운 기능
- fix: → 버그 수정
- style: → CSS/UI 변경
- refactor: → 코드 개선
- docs: → 문서 수정
- chore: → 환경 설정, 예제 제거, 설정 변경

## 주요 기능
데일리 기록
- 칼로리
- 음수량
- 식단 기록
- 하루 만족도

## 기본 기능

| 식단앱 기능  | 배우는 React 개념 |
| ------- | ------------ |
| 제목 출력   | JSX          |
| 음식 입력창  | useState     |
| 추가 버튼   | 이벤트(onClick) |
| 목록 출력   | map          |
| 삭제      | state 업데이트   |
| 총 칼로리   | reduce       |
| 새로고침 유지 | localStorage |
| 페이지 분리  | 컴포넌트         |
| 기록 저장   | Supabase     |
